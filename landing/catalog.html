NightSeam Catalog

A desktop app that turns a folder of exposures into an organized archive.

DownloadSource on GitHub

Free and open source (MIT). Windows and Linux. Works without an internet connection.

Import

FITS files, including .fits.gz and .fz, one by one or a whole folder. Duplicates are recognized by content.

Objects and nights

Exposures are sorted by object. A night runs from sunset to sunrise at the observing site.

Calibration frames

Darks, flats and bias attach to their session and keep their capture dates.

Sky map

Browse your archive on a map of the sky.

Archive Health

Find missing, changed or unindexed files. A scan never changes anything.

Lossless compression

Compress sessions to save space. Every file restores byte for byte.

Download

Windows ↓

64-bit ZIP. Unzip it and run NightSeam.exe.

Linux ↓

x86_64 archive with Python included. Opens in your web browser.

Both come from the latest GitHub release, each with a SHA-256 checksum. The Catalog is a separate app from the planner, with its own versions.
